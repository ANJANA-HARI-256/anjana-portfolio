ANJANA HARI - PORTFOLIO WEBSITE

Files:
- index.html: website content
- style.css: responsive styling
- script.js: mobile navigation and footer year

HOW TO VIEW:
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to open it in your browser.

HOW TO EDIT:
- Update text and links in index.html.
- Change colors and layout in style.css.
- Replace the decorative project panels with real screenshots only if you have permission and accurate screenshots.

HOW TO PUBLISH:
You can publish this static website with GitHub Pages:
1. Create a new public repository on GitHub (for example, anjana-portfolio).
2. Upload index.html, style.css and script.js to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. GitHub will provide a public website URL after deployment.

IMPORTANT:
- Check the phone number, email, education details and links before publishing.
- The major project is clearly marked as ongoing.
- Project-specific technologies have not been invented or added.
